## 📌 Overview

SMARTCAREER AI is a Python-based Resume Analysis and Career Recommendation Platform designed to help candidates understand their resumes, identify skill gaps, and explore suitable career opportunities.

The application analyzes uploaded PDF resumes and generates useful career insights through an interactive Streamlit dashboard.

## ✨ Key Features

- PDF Resume Upload
- Candidate Name, Email and Phone Extraction
- Technical Skills Detection and Categorization
- Estimated ATS Resume Scoring
- Resume Score Breakdown
- Missing Skills Identification
- Job Role Recommendations
- Personalized Learning Roadmap
- PDF and TXT Report Generation
- Interactive Streamlit Dashboard

## ⚙️ Installation and Setup

### 1. Clone Repository

```bash
git clone https://github.com/sagar176206-sketch/SMARTCAREER-AI.git
```

### 2. Open Project Folder

```bash
cd SMARTCAREER-AI
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run Application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## 🔍 How It Works

1. Upload a candidate's PDF resume.
2. Extract resume text and candidate information.
3. Detect and categorize technical skills.
4. Calculate an estimated ATS score.
5. Identify missing skills.
6. Recommend suitable job roles.
7. Explore a learning roadmap.
8. Generate downloadable PDF or TXT reports.

## 📊 Application Modules

1. Dashboard
2. Resume Analysis
3. Skill Gap Analysis
4. Job Matches
5. Learning Roadmap
6. Reports

## ⚠️ Important Notes

- ATS scores are project-based estimates, not official employer ATS scores.
- Job recommendations use predefined skill databases and matching logic.
- The application does not currently fetch live job vacancies.
- Analysis accuracy may vary depending on PDF formatting and content.
- Uploaded resumes may contain personal information. Handle them responsibly.
